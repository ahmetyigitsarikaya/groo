## Reporting Bugs & Requesting Features

Once hosted on GitHub, please use GitHub Issues to report non-security bugs or propose enhancements. Include:

- PHP version (`php -v`), web server (Apache/Nginx), and MySQL/MariaDB version
- Active plugins (`ACTIVE_PLUGINS`) and active template (`ACTIVE_TEMPLATE`)
- Exact steps to reproduce, expected behavior, and observed behavior (redacting any credentials or sensitive data from `.env` or stack traces)

## Security Vulnerabilities

Do **not** use public issues for security vulnerabilities. Follow [`SECURITY.md`](SECURITY.md).
