# Documentation Visual Assets

This directory is reserved for curated, sanitized screenshots and visual documentation assets for **Groo (`groo/core`)**.

No screenshots are included yet because the only images currently present in the workspace belong to a client deployment (`DualTesisat`) and must not be showcased as generic core documentation.

## Recommended Screenshots to Capture Later

When capturing screenshots from a clean local installation (`ACTIVE_TEMPLATE=default`, dummy demo data only — **no real client PII, domains, or phone numbers**):

1. `docs/assets/installer-wizard.png` — Step 1 or Step 2 of the standalone setup wizard (`/install/index.php`).
2. `docs/assets/admin-dashboard.png` — Admin control panel dashboard (`/<ADMIN_PATH>`) showing overview cards and CRM widgets.
3. `docs/assets/content-editor.png` — Block-based post editor (`/<ADMIN_PATH>/posts/create`).
4. `docs/assets/crm-board.png` — CRM contacts or tasks/calendar view (`/<ADMIN_PATH>/crm/tasks`).
5. `docs/assets/traffic-analytics.png` — Traffic analytics Chart.js dashboard (`/<ADMIN_PATH>/traffic`).
6. `docs/assets/seo-manager.png` — SEO meta/sitemap management interface (`/<ADMIN_PATH>/seo`).

### Screenshot Guidelines

- Use `1440×900` (or `1280×720`) viewport resolution at `1x` or `2x` DPR.
- Export as optimized `.png` or `.webp` under 500 KB per image.
- Use generic placeholder data (`example.com`, `admin@groo.test`, sample titles) with zero personal information.
